# Contributing to Italian LLM

Grazie per il tuo interesse nel contribuire a Italian LLM! 🎉

## Come Contribuire

### 1. Fork e Clone
```bash
git clone https://github.com/tuousername/italian-llm.git
cd italian-llm
```

### 2. Crea un Branch
```bash
git checkout -b feature/nome-featura
```

### 3. Installa Dipendenze
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
```

### 4. Fai le Modifiche
- Segui PEP 8 per il codice Python
- Aggiungi docstring alle funzioni
- Includi test se applicabile

### 5. Testa
```bash
make test
```

### 6. Commit e Push
```bash
git add .
git commit -m "feat: aggiunta feature X"
git push origin feature/nome-feature
```

### 7. Pull Request
Apri una PR su GitHub con una descrizione chiara delle modifiche.

## Guidelines

- **Codice**: segui PEP 8, usa type hints
- **Commit messages**: usa Conventional Commits (feat:, fix:, docs:, etc.)
- **Documentation**: aggiorna README e docstrings
- **Dataset**: assicurati che i dati siano in italiano e di qualità

## Domande?

Apri un issue o contatta i maintainer.
